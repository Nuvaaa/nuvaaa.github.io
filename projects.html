Tomodachi Life Printer

This is a script that communicates with a microcontroller to print an image in tomodachi life. Currently I'm using arduino code from this github for the controller, but I might make smthn myself sometime.

The script is made in python, and will take a json file from Living the Grid and convert it into a series of moves that reproduces the image in-game.

I might move the code a lil so it can be used for images in splatoon as well later on.

I have a bunch of parts and tools coming in to take this beyond a pile of wires and boards on my desk.

untitled fishing game

This fishing game is meant to be a cozy roguelike. You are put in a top down veiw of the water, and have to catch the fish by reacting with the correct directional imput before they get away.

Once you run out of bait you can enter a shop to gain items and make it easier to catch fish

Currently there are 8 areas and 52 fish planned. idk how many items there'll be but I wanna have the capacity for many powerful builds.

This is a shared project between a friend and I. I can't art :3

Figura Model
